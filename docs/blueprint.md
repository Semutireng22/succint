# **App Name**: Succint ZkProof Simulator

## Core Features:

- Project Display: Display project overview in a macOS terminal-style window with Succinct integration comparison.
- Interactive Simulation: Allow users to input transaction counts and visualize cost and time savings with Succinct.
- Data Processing: Calculates and compares transaction costs and verification times with and without Succinct Labs' technology based on user input.

## Style Guidelines:

- Primary color: Pink (#FF69B4) for main elements and highlights.
- Secondary colors: Dark gray (#333333) and white (#FFFFFF) for backgrounds and text to provide contrast.
- Accent: Teal (#008080) for interactive elements and to complement the pink.
- Monospace font (e.g., SF Mono, Menlo) to mimic a terminal aesthetic.
- macOS-style window controls (red, yellow, green) for interactive panels.
- Terminal-like windows with blurred background and soft shadows for an immersive experience.
- Subtle animations for interactive elements and data visualization to provide smooth transitions.
